# Codex Instructions

## Project

The repository root is:

```text
spaghettichef-angular
```

The Angular application is located in:

```text
spaghettichef-angular/spangular
```

Angular 19.2.x is already installed.

Node.js 22 is already installed.

The Angular project has already been created.

Do not recreate the project.

## Goal

Implement a small Angular learning application that consumes the SpaghettiChef REST API.

This project is intentionally simple.

The objective is learning Angular, routing, services, HttpClient, templates, and component organization.

---

## Scope

Pages:

```text
/dashboard
/printers
/settings
```

Read-only application.

No authentication.

No backend.

No Django.

No write operations.

---

## API

Base URL:

```text
http://localhost:18080
```

Endpoints:

```text
GET /monitoring
GET /printers
GET /settings/monitoring
```

Detailed API contracts are documented in:

```text
docs/api-contract.md
```
